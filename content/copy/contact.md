## Inquiry form

Fields: name, email, phone (optional), project type (select: new build,
renovation, structural audit, project management, advisory, other), county or
location, brief description.

Behaviour: client-side validation with clear inline errors, then compose a
mailto to info@sosengineeringke.com with a formatted body. No data is sent
anywhere else. If SOSE later wants tracked inquiries, swap the submit handler
for a POST to a form endpoint; keep the same validation.

Empty state and errors speak plainly. "Enter an email we can reply to", not
"Invalid input".

Note under the form: We reply to every inquiry. If your project is urgent, say so
in the first line.
